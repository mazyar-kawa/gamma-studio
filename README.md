# Gamma Gradients

Ambient UI gradients built with layered CSS blend modes. Backgrounds that feel like light — with a much larger pattern catalog.

Based on [Aura](https://github.com/CristianOlivera1/Aura) by Cristian Olivera (MIT).

## Features

- Live hover preview and a fullscreen customizer (undo/redo, grain, blend modes)
- 14 categories: Aura, Mesh, Nebula, Prism, Lattice, Grain, Glass, Flux, Waves, Aurora, Geometric, Noise, Halo, Dusk
- 500+ hand-tuned and seeded patterns
- Export CSS, Tailwind, CSS variables, CSS-in-JS, PNG, and SVG
- One-click AI prompt for ChatGPT, Claude, or Copilot

## Quick start

```bash
bun install
bun dev
```

Open [http://localhost:3000](http://localhost:3000).

| Command     | Description      |
| ----------- | ---------------- |
| `bun dev`   | Start dev server |
| `bun build` | Production build |
| `bun lint`  | Run ESLint       |
